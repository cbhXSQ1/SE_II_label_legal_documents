## 一、说明

功能层接收页面请求，核对身份凭证，取出账号与角色，判断这个身份能不能做这个操作，算出可以查看的数据范围，按用例顺序调用下层，最后把结果、数据、提示和下一步可做的操作组装成响应返回页面。

功能层的下层分两类。规则层接收输入、返回判断与计算结果，只做计算，不读写文件和 MySQL。数据层按功能层给出的范围读写数据，只做保存与读取，不判断角色，不做业务规则。通知单独列出，功能层在审批、任务发布、退回修改、专家回复和教师反馈时调用。

每一层各认一件事。身份凭证的核对、操作权限的判断、数据范围的计算、用例顺序的安排落在功能层；切分、要素、关系、图示、差异度、评分这些判断与计算落在规则层；账号、任务、标注、作答、裁定、班级这些记录的保存与读取落在数据层。

## 二、通用约定

**身份凭证**：每条请求带登录凭证，功能层先调用数据层读取登录凭证，凭证有效且账号处于启用状态时继续，凭证失效或账号停用时返回“登录已失效，请重新登录”。

**本次身份**：登录凭证里保存本次进入的系统和身份，功能层按本次身份取出角色，角色以账号为准，调用方带来的身份选择只作为本次进入的入口。

**数据范围**：功能层按身份算出范围后传给数据接口，范围包括本人任务、本任务全部提交、本班、本人作答、两个系统总体情况、教学系统账号与班级；数据接口按范围取数，范围以外的记录不返回。

**分页**：列表接口接收页码和每页数量，返回当前页记录、总记录数和总页数；页码从 1 开始，每页数量默认 20。

**时间**：时间统一用“年-月-日 时:分:秒”，跨时区按学校所在时区。

**百分比**：差异度、一致度、得分和平均分保留一位小数，页面上带百分号。

**文件**：上传接口接收文件名、文件格式和文件内容，返回文件标识；读取接口按文件标识返回文件名、文件格式和文件内容；删除接口按文件标识删除文件并返回成功。

**防止重复提交**：提交类接口接收请求标识；请求标识按操作类型、账号和请求标识判重；同键同内容返回第一次的记录标识，同键不同内容返回冲突并提示“请求标识已用于其他内容”；功能层在同一个事务里调用保存记录、更新任务状态和登记请求标识，数据层的保存方法参与这个事务。

**轮次实例**：每次重开本轮生成新的 roundId，RoundType 只表示切分或结构化；提交、切分版本、草稿、裁定记录和最终版本带 roundId；默认查询当前轮次，查看历史按旧 roundId 读取。

**阶段版本**：saveElements 和 saveRelations 每次保存生成新的版本标识；按版本标识读回指定版本，按上游标识读回最新版本；比对、裁定和导出记录使用的版本标识。

**失败返回**：数据层和规则层返回失败时带具体提示，功能层把提示显示在页面字段旁边或页面顶部，页面保留用户已经填写的内容。

## 三、包结构与公共类型

### 1. 包结构

后端按 app、function、rule、data、common 五个顶层包组织，app 放启动类，function 下分 controller、service、dto、support、event，rule 下按身份、指南、任务、标注、裁定、导出、教学、通知、通用和具体类分开，data 下分 repository、entity、mysql，common 下分 result、page、enums、exception。

模块归属：

| 包 | Maven 模块 |

| `com.seii.legal.data.mysql` | `legal-data-mysql` |

## 四、通知接口

**发送站内消息**：输入接收人、消息内容、消息类型、发送时间；输出消息标识；调用方是审批结果、任务发布、任务修改、退回修改、专家回复和教师反馈。

**发送邮件**：输入收件人、邮件主题、邮件内容、发送时间；输出发送结果；调用方是审批结果和需要邮件通知的事项；学校邮件服务不可用时返回失败并保留站内消息。

## 五、功能层调用示例

功能层服务按用例顺序调用下层，下面的裁定服务示例先读登录凭证和账号，调用身份规则判断角色和范围，调用数据接口取提交，调用裁定规则算差异，最后组装响应；控制器只接收请求和凭证，把请求交给服务。

```java
package com.seii.legal.function.service;

import com.seii.legal.common.enums.DataScope;
import com.seii.legal.common.enums.IdentityType;
import com.seii.legal.common.enums.LoginUser;
import com.seii.legal.common.enums.RoundType;
import com.seii.legal.common.result.AppResult;
import com.seii.legal.data.entity.Account;
import com.seii.legal.data.entity.AdjudicationRecord;
import com.seii.legal.data.entity.Agreement;
import com.seii.legal.data.entity.AnnotationTask;
import com.seii.legal.data.entity.Submission;
import com.seii.legal.data.repository.AccountRepository;
import com.seii.legal.data.repository.AdjudicationRepository;
import com.seii.legal.data.repository.AnnotationRepository;
import com.seii.legal.data.repository.SessionRepository;
import com.seii.legal.data.repository.TaskRepository;
import com.seii.legal.rule.adjudication.AdjudicationRule;
import com.seii.legal.rule.identity.IdentityRule;

import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.util.List;

@Service
@RequiredArgsConstructor
public class AdjudicationAppService {

    private final SessionRepository sessionRepository;
    private final AccountRepository accountRepository;
    private final TaskRepository taskRepository;
    private final AnnotationRepository annotationRepository;
    private final AdjudicationRepository adjudicationRepository;
    private final IdentityRule identityRule;
    private final AdjudicationRule adjudicationRule;

    @Transactional
    public AppResult<CompareResult> compare(String credential, CompareCommand command) {
        LoginUser user = sessionRepository.findByCredential(credential)
                .orElseThrow(() -> new IllegalStateException("登录已失效，请重新登录"));
        Account account = accountRepository.findById(user.accountId())
                .orElseThrow(() -> new IllegalStateException("账号不存在"));
        if (!identityRule.hasRole(account, IdentityType.ARBITER)) {
            return AppResult.fail("只有本任务仲裁员可以裁定");
        }
        DataScope scope = identityRule.resolveScope(user, command.taskId(), null);
        if (scope != DataScope.TASK_SUBMISSIONS) {
            return AppResult.fail("当前身份不能查看这个任务的提交");
        }
        AnnotationTask task = taskRepository.findById(command.taskId())
                .orElseThrow(() -> new IllegalStateException("任务不存在"));
        if (!task.arbiterId().equals(user.accountId())) {
            return AppResult.fail("只有本任务仲裁员可以裁定");
        }
        List<Submission> submissions = annotationRepository.findSubmissions(
                command.taskId(), command.documentId(), command.round(), null);
        Submission a = submissions.stream()
                .filter(item -> item.annotatorId().equals(command.annotatorA()))
                .findFirst()
                .orElseThrow(() -> new IllegalStateException("甲的提交不存在"));
        Submission b = submissions.stream()
                .filter(item -> item.annotatorId().equals(command.annotatorB()))
                .findFirst()
                .orElseThrow(() -> new IllegalStateException("乙的提交不存在"));
        Agreement agreement = adjudicationRule.difference(a.content(), b.content(), command.round());
        CompareResult result = new CompareResult(
                agreement.agreement(),
                agreement.difference(),
                agreement.items(),
                List.of("进入裁定冲突", "切换标注员对")
        );
        return AppResult.ok(result, result.allowedActions());
    }

    @Transactional
    public AppResult<Void> decide(String credential, DecideCommand command) {
        LoginUser user = sessionRepository.findByCredential(credential)
                .orElseThrow(() -> new IllegalStateException("登录已失效，请重新登录"));
        Account account = accountRepository.findById(user.accountId())
                .orElseThrow(() -> new IllegalStateException("账号不存在"));
        if (!identityRule.hasRole(account, IdentityType.ARBITER)) {
            return AppResult.fail("只有本任务仲裁员可以裁定");
        }
        AnnotationTask task = taskRepository.findById(command.taskId())
                .orElseThrow(() -> new IllegalStateException("任务不存在"));
        if (!task.arbiterId().equals(user.accountId())) {
            return AppResult.fail("只有本任务仲裁员可以裁定");
        }
        AdjudicationRecord record = new AdjudicationRecord(
                null,
                command.taskId(),
                command.documentId(),
                command.round(),
                command.conflictId(),
                command.differenceType(),
                command.differenceObject(),
                command.valueA(),
                command.valueB(),
                command.method(),
                command.result(),
                user.accountId(),
                LocalDateTime.now(),
                command.expertReplyId()
        );
        adjudicationRepository.saveDecision(record);
        return AppResult.ok(null, List.of("继续裁定", "查看未裁定项"));
    }

    public record CompareCommand(
            String taskId,
            String documentId,
            RoundType round,
            String annotatorA,
            String annotatorB
    ) {
    }

    public record DecideCommand(
            String taskId,
            String documentId,
            RoundType round,
            String conflictId,
            String differenceType,
            String differenceObject,
            String valueA,
            String valueB,
            String method,
            String result,
            String expertReplyId
    ) {
    }

    public record CompareResult(
            double agreement,
            double difference,
            List<com.seii.legal.data.entity.DiffItem> items,
            List<String> allowedActions
    ) {
    }
}
```

```java
package com.seii.legal.function.controller;

import com.seii.legal.common.result.AppResult;
import com.seii.legal.function.service.AdjudicationAppService;

import lombok.RequiredArgsConstructor;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestHeader;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/app/adjudication")
@RequiredArgsConstructor
public class AdjudicationController {

    @PostMapping("/compare")

    @PostMapping("/decide")
    public AppResult<Void> decide(
            @RequestHeader("Authorization") String credential,
            @RequestBody AdjudicationAppService.DecideCommand command) {
        return adjudicationAppService.decide(credential, command);
    }
}
```

## 六、调用顺序示例

### 1. 登录

功能层接收账号和密码，调用数据层“读取账号”取得账号记录，调用规则层“账号状态判定”判断启用或停用，调用规则层“角色判定”和“多身份选择”得到可以进入的系统和身份，只有一个系统和身份时调用数据层“保存登录凭证”并返回首页数据，有多个系统和身份时返回选择页需要的数据。

### 2. 创建任务

功能层核对身份和角色，调用规则层“数据范围判定”得到任务管理者的范围，调用数据层“读取可用指南版本列表”“读取文书”“读取账号角色”取得可选内容，调用规则层“发布条件检查”“标注员数量检查”“仲裁员唯一检查”检查任务草稿，检查通过后调用数据层“保存标注任务”“保存任务分配”“更新任务状态”，再调用通知接口“发送站内消息”通知标注员和仲裁员。

### 3. 提交标注

功能层核对身份和角色，调用规则层“截止检查”“任务状态转换”确认可以提交，调用规则层“未切分检查”“要素完整检查”“孤立命题检查”列出未完成项，标注员确认后调用数据层“保存提交记录”和“更新提交状态”，提交记录保存后调用规则层“进度统计”更新任务进度。

### 4. 比对与裁定

功能层核对仲裁员身份和范围，调用数据层“读取提交记录”“读取文书”“读取指南版本”，调用规则层“差异度”“差异项分类”“80% 线”得到差异度和差异项；仲裁员逐条裁定后，功能层调用规则层“任务状态转换”“最终版本条件”，调用数据层“保存裁定记录”，切分轮裁定完后调用数据层“保存最终版本”保存统一切分版本，结构化轮裁定完并审查通过后调用数据层“保存最终版本”和“更新任务状态为已确认”。

### 5. 学生作答与评分

功能层核对身份和范围，调用数据层“读取练习任务”“读取题目版本”“读取指南版本”，学生提交后调用数据层“保存作答记录”，调用规则层“评分规则”“差异度”“差异项分类”“任务得分平均”得到得分和差异明细，调用数据层“保存差异明细”和“读取学习情况统计”，最后返回得分、差异明细和系统反馈。

### 6. 导入班级和学生名单

功能层核对教学系统管理员身份，调用数据层“保存文件”保存上传的 Excel，调用规则层“导入行检查”“班级编号唯一”“学号唯一”“教师工号匹配”“学生单班级”，调用数据层“保存班级”“保存班级成员”“按学号读取账号”“自动创建学生账号”“保存导入记录”，最后返回成功班级数、成功学生数和失败行。
