# 标注系统数据层

第一批实现覆盖标注轮次和正式提交。Java 17、Spring JDBC、MySQL 8.0。接口及实体对应仓库的[功能层需求](../接口文档/后端/功能层/对数据层.md)。后续任务、标注方法可按功能逐步补充。

## 接入

在空的业务库上执行一次 [建表脚本](src/main/resources/db/mysql/V001__rounds_and_submissions.sql)。在本目录运行 `mvn package` 构建数据层 JAR。Spring Boot 应用引入此模块后，将 `com.seii.legal.data.mysql` 纳入组件扫描，并配置 MySQL 数据源。Service 通过构造器注入 `TaskRepository` 和 `AnnotationRepository`。需要同时关闭旧轮、创建新轮，或同时保存提交和任务状态时，由 Service 的 `@Transactional` 包含全部调用。

## 读写约定

- 新建轮次传打开时间和序号，状态可传 `OPEN`，关闭时记录时间并返回 `CLOSED` 状态。空记录标识由数据层生成。任务、文书和类型相同的轮次最多一个处于打开状态。
- 默认提交查询只返回当前打开轮次的有效提交。按轮次实例查询可读取该轮的记录及状态。关闭轮次后不能新增或修改提交，原请求重试仍能取回原标识。
- 正式提交的请求标识在该标注员的正式提交操作内唯一。重试须使用相同的轮次、指南版本及原始内容字符串。提交时间不参与内容比较。一个轮次内同一人最多有一份有效提交，已退回后可持新请求标识重新提交。
- MySQL 唯一约束处理并发写入。提交记录本身保存请求标识，状态变更和审计记录共同提交。角色权限、内容校验和任务流程由调用方决定。

## 验证

集成测试需要一个新的空 MySQL 8 测试库。设置 `LEGAL_TEST_JDBC_URL`、`LEGAL_TEST_DB_USER`、`LEGAL_TEST_DB_PASSWORD` 后，在本目录执行 `mvn test`。测试会创建表并写入数据。未设置测试连接时跳过这些用例。
